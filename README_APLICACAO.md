# ATLAS Scanner Patch

## Passos
1. Copie `atlas_scanner_patch.py` e `apply_atlas_scanner_patch.py` para a raiz do projeto
2. Execute: `python apply_atlas_scanner_patch.py`
3. No bot, após criar o Application, adicione: `register_atlas_scanner(application)`

## Comandos Telegram
- /scanner on
- /scanner off
- /scanner status
- /scanner intervalo 5
- /scanner ativos BTC/USDT,ETH/USDT,SOL/USDT
- /scanner timeframe 5m
